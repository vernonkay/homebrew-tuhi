# homebrew-tuhi

A [Homebrew](https://brew.sh) tap for [**tuhi**](https://github.com/vernonkay/tuhi) — a fast, cross-platform text & Markdown editor that opens multi-gigabyte files without flinching.

## Install

    brew install --cask vernonkay/tuhi/tuhi

or

    brew tap vernonkay/tuhi
    brew install --cask tuhi

## First launch (unsigned)

tuhi isn't notarized yet, so macOS Gatekeeper will block it the first time. Right-click **tuhi** in Applications and choose **Open**, then confirm — or allow it under **System Settings → Privacy & Security → Open Anyway**. After that it opens normally.

## Updating

    brew upgrade --cask tuhi
